# Node API v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the four `/v1/nodes/` endpoints of the phase 1 ADR, on Alembic-managed tables, with the Mender lookup called in-request, so a real enrolled node can register, stream detections and heartbeat against production.

**Architecture:** New SQLAlchemy models in `core/nodes.py` reusing the existing `Base` and engine from `core/users.py`, migrated by Alembic (introduced here for the first time). Three in-memory caches live in `core/node_state.py` in the single uvicorn process: token to node, active config version per node, and last frame arrival per node. The Mender management API is called during registration behind one function in `services/mender.py`, so tests inject a fake. All four endpoints live in `routes/nodes.py` with request and response models in `routes/node_schemas.py`.

**Tech Stack:** Python 3.12, FastAPI 0.109 + uvicorn, SQLAlchemy 2 async with `aiosqlite`, Alembic, httpx, pytest, ruff.

## Global Constraints

- Coverage gate is `--cov-fail-under=55` in `backend/pyproject.toml` and runs on every pytest invocation. When running a single test file, add `--no-cov` or the run fails on coverage rather than on the test.
- Lint is two separate commands and both must pass: `backend/.venv/bin/ruff check backend/` and `backend/.venv/bin/ruff format backend/`. `ruff check` alone leaves formatting diffs.
- `line-length = 120`, `target-version = "py312"`, ruff rule set `E,W,F,I,B,UP,S,SIM`.
- Install new dependencies with `uv pip install --python backend/.venv/bin/python <pkg>` and pin them in `backend/requirements.txt`.
- uvicorn stays at `--workers 1`. The three caches in `core/node_state.py` are per-process; a second worker halves the liveness view and doubles the revocation delay.
- Every migration uses `op.batch_alter_table` for anything other than `create_table`. SQLite cannot `ALTER`.
- The wire contract is `~/owl/nodes_api_v1.yml`. Where this plan and the spec disagree, the spec wins and the disagreement is a bug in this plan.
- Writing style for any doc or comment changed here: no em-dashes, British spellings, state each fact once.

## Error taxonomy

The spec fixes the status codes. This is the server-side mapping, and it is the contract the node client is written against.

| Condition | Status | Body | Retryable by node |
|---|---|---|---|
| Registration succeeded | 200 | `RegisterResponse` | n/a |
| Config failed validation (register or config) | 400 | `{"error": "invalid_config", "detail": "<field>"}` | no, not unchanged |
| Agreements missing or malformed | 400 | `{"error": "invalid_agreements", "detail": "<field>"}` | no, not unchanged |
| Unknown device, device not accepted, already holds a valid token, identity in cooldown | 403 | `{"error": "forbidden"}` | yes, after `Retry-After` |
| Mender unreachable | 403 | `{"error": "forbidden"}` | yes, after `Retry-After` |
| Per-IP or global registration limit | 429 | `{"error": "rate_limited"}` | yes, after `Retry-After` |
| Bearer token absent, unknown, revoked or expired | 401 | `{"error": "unauthorized"}` | no, do not re-register |
| Detection frame carries an unknown `config_version` | 409 | `{"error": "unknown_config_version"}` | yes, after `PUT /nodes/config` |
| Per-token rate limit | 429 | `{"error": "rate_limited"}` | yes, after `Retry-After` |
| Unhandled server fault | 500 | `{"error": "server_error"}` | yes, with backoff |

Two rules that are requirements rather than preferences, both from the ADR:

1. The rate limiters run before the Mender call (D26). An unauthenticated endpoint that makes an outbound authenticated call per request is an amplifier in any other order.
2. Configuration validation runs after identity resolution (D28). A 400 reachable before it turns the difference between 400 and 403 into an oracle for which identities exist.

Every 403 from registration is byte-identical and answers at the same latency, whatever caused it.

```python
import asyncio

from alembic import context
from sqlalchemy.ext.asyncio import create_async_engine

from core.users import DATABASE_URL, Base

target_metadata = Base.metadata


def _run(connection) -> None:
    context.configure(
        connection=connection,
        target_metadata=target_metadata,
        render_as_batch=True,
    )
    with context.begin_transaction():
        context.run_migrations()


async def run_online() -> None:
    engine = create_async_engine(DATABASE_URL)
    async with engine.connect() as connection:
        await connection.run_sync(_run)
        await connection.commit()
    await engine.dispose()


if context.is_offline_mode():
    context.configure(url=DATABASE_URL, target_metadata=target_metadata, literal_binds=True)
    with context.begin_transaction():
        context.run_migrations()
else:
    asyncio.run(run_online())
```

`render_as_batch=True` is what makes autogenerated alters use `batch_alter_table` on SQLite.

```python
"""Node-side data model for the v1 API.

Column set is §6 of the phase 1 ADR. Five columns are created here and read by
nothing in phase 1: archive_ref, publication, publication_quiet_until and the two
display-offset components. They belong to the archive design, and adding a column
to a table being created is free where adding one afterwards is a migration.
"""

from datetime import datetime

from sqlalchemy import Boolean, DateTime, Float, ForeignKey, Integer, String, func
from sqlalchemy.orm import Mapped, mapped_column

from core.users import Base

NODE_STATUSES = ("active", "retired", "blocked")
PUBLICATION_CHOICES = ("public", "private")


class Node(Base):
    __tablename__ = "nodes"

    node_id: Mapped[str] = mapped_column(String(32), primary_key=True)
    node_ref: Mapped[str] = mapped_column(String(15), unique=True, index=True)
    archive_ref: Mapped[str] = mapped_column(String(15), unique=True, index=True)
    board_model: Mapped[str] = mapped_column(String(64), default="", server_default="")
    owner_id: Mapped[str | None] = mapped_column(String(36), ForeignKey("user.id"), nullable=True)
    status: Mapped[str] = mapped_column(String(16), default="active", server_default="active")
    publication: Mapped[str] = mapped_column(String(8), default="public", server_default="public")
    publication_quiet_until: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    display_offset_m_e: Mapped[float] = mapped_column(Float, default=0.0, server_default="0")
    display_offset_m_n: Mapped[float] = mapped_column(Float, default=0.0, server_default="0")
    fleet_name: Mapped[str | None] = mapped_column(String(64), nullable=True)
    is_synthetic: Mapped[bool] = mapped_column(Boolean, default=False, server_default="0")
    licence_version: Mapped[str | None] = mapped_column(String(32), nullable=True)
    licence_accepted_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    remote_management_version: Mapped[str | None] = mapped_column(String(32), nullable=True)
    remote_management_accepted_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    publication_version: Mapped[str | None] = mapped_column(String(32), nullable=True)
    publication_chosen_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    node_ref_rotated_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    node_ref_rotation_deferred_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    reactivated_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    reactivated_by: Mapped[str | None] = mapped_column(String(36), nullable=True)
    reactivation_note: Mapped[str | None] = mapped_column(String(512), nullable=True)
    active_config_version: Mapped[int] = mapped_column(Integer, default=0, server_default="0")
    first_seen_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
    last_seen_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
```

It is added because §5 requires the active version to be resolvable on the detection path, and denormalising it onto `nodes` keeps that a cache read rather than a join. Record this in the commit message so it is not mistaken for a transcription error.

```python
"""Public identifier minting and the one authority on whether a node is synthetic.

`is_synthetic` on the row is the authority and no code branches on a prefix. The
prefix carries the answer only in the archive, where a partition key has no join
back to the database.
"""

import secrets

_ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyz"
_RANDOM_LEN = 12

_synthetic_by_node_id: dict[str, bool] = {}


def _mint(prefix: str) -> str:
    return prefix + "".join(secrets.choice(_ALPHABET) for _ in range(_RANDOM_LEN))


def mint_node_ref(*, is_synthetic: bool) -> str:
    """Fifteen characters whichever kind, roughly 62 bits after the prefix."""
    return _mint("sim" if is_synthetic else "nde")


def mint_archive_ref() -> str:
    return _mint("arc")


def set_synthetic(node_id: str, is_synthetic: bool) -> None:
    """Populate the accessor's view. Called when a node row is created or loaded."""
    _synthetic_by_node_id[node_id] = is_synthetic


def is_synthetic_node(node_id: str) -> bool:
    """The single authority. An identity we do not know is treated as synthetic.

    Resolving the unknown case to synthetic keeps an unrecognised identity out of
    real-fleet aggregates. The opposite default silently inflates them, and nothing
    announces it.
    """
    return _synthetic_by_node_id.get(node_id, True)
```

```python
"""The one configuration validator, shared by registration and PUT /nodes/config.

Bounds are the wire contract's, in nodes_api_v1.yml. Two checks are here and not
there because a JSON schema cannot express them: a receiver and illuminator at the
same point give the solver a degenerate baseline, and bool is a subclass of int in
Python, so a plain range check accepts True as a latitude of 1.
"""

from typing import Any

_MIN_BASELINE_DEG = 1e-6


class ConfigInvalid(Exception):
    def __init__(self, field: str, reason: str = "out of range") -> None:
        super().__init__(f"{field}: {reason}")
        self.field = field
        self.reason = reason


_NUMERIC_BOUNDS: dict[str, tuple[float, float, bool, bool]] = {
    "rx_lat": (-90, 90, True, True),
    "rx_lon": (-180, 180, True, True),
    "rx_alt_ft": (-1500, 30000, True, True),
    "tx_lat": (-90, 90, True, True),
    "tx_lon": (-180, 180, True, True),
    "tx_alt_ft": (-1500, 30000, True, True),
    "fc_hz": (1_000_000, 6_000_000_000, True, True),
    "fs_hz": (100_000, 20_000_000, True, True),
    "beam_width_deg": (0, 360, False, True),
    "max_range_km": (0, 1000, False, True),
}

_REQUIRED = set(_NUMERIC_BOUNDS) | {"tx_callsign", "beam_azimuth_deg"}


def _number(field: str, value: Any) -> float:
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        raise ConfigInvalid(field, "not a number")
    return float(value)


def validate_config(payload: dict[str, Any]) -> dict[str, Any]:
    """Return the normalised configuration, or raise ConfigInvalid naming one field."""
    for field in sorted(set(payload) - _REQUIRED):
        raise ConfigInvalid(field, "unknown field")
    for field in sorted(_REQUIRED - set(payload)):
        raise ConfigInvalid(field, "missing")

    out: dict[str, Any] = {}
    for field, (low, high, low_inclusive, high_inclusive) in _NUMERIC_BOUNDS.items():
        value = _number(field, payload[field])
        below = value < low if low_inclusive else value <= low
        above = value > high if high_inclusive else value >= high
        if below or above:
            raise ConfigInvalid(field)
        out[field] = value

    callsign = payload["tx_callsign"]
    if not isinstance(callsign, str) or not 1 <= len(callsign) <= 32:
        raise ConfigInvalid("tx_callsign")
    out["tx_callsign"] = callsign

    azimuth = payload["beam_azimuth_deg"]
    if azimuth is None:
        out["beam_azimuth_deg"] = None
    else:
        azimuth = _number("beam_azimuth_deg", azimuth)
        if not 0 <= azimuth < 360:
            raise ConfigInvalid("beam_azimuth_deg")
        out["beam_azimuth_deg"] = azimuth

    if (
        abs(out["rx_lat"] - out["tx_lat"]) < _MIN_BASELINE_DEG
        and abs(out["rx_lon"] - out["tx_lon"]) < _MIN_BASELINE_DEG
    ):
        raise ConfigInvalid("tx_lat", "receiver and illuminator are at the same point")

    return out
```

```python
"""The three per-process caches the ingest path reads.

All three live in the uvicorn process and nowhere else, which is why the service
runs at --workers 1: a second worker halves the liveness view and doubles the
revocation delay, silently in both cases.
"""

import hashlib
import time

_token_to_node: dict[str, str] = {}
_active_config: dict[str, int] = {}
_status: dict[str, str] = {}
_last_frame_at: dict[str, float] = {}


def reset() -> None:
    """Drop every cache. Tests only."""
    _token_to_node.clear()
    _active_config.clear()
    _status.clear()
    _last_frame_at.clear()


def token_hash(token: str) -> str:
    return hashlib.sha256(token.encode()).hexdigest()


def prime_token(hashed: str, node_id: str) -> None:
    _token_to_node[hashed] = node_id


def forget_token(hashed: str) -> None:
    _token_to_node.pop(hashed, None)


def forget_node(node_id: str) -> None:
    for hashed in [h for h, n in _token_to_node.items() if n == node_id]:
        del _token_to_node[hashed]


def resolve_token(token: str) -> str | None:
    return _token_to_node.get(token_hash(token))


def set_active_config(node_id: str, version: int) -> None:
    _active_config[node_id] = version


def active_config(node_id: str) -> int | None:
    return _active_config.get(node_id)


def set_status(node_id: str, status: str) -> None:
    _status[node_id] = status


def streaming_allowed(node_id: str) -> bool:
    """True only for an explicitly active node. Unknown is not allowed."""
    return _status.get(node_id) == "active"


def note_frame(node_id: str, at: float | None = None) -> None:
    _last_frame_at[node_id] = time.monotonic() if at is None else at


def last_frame_at(node_id: str) -> float | None:
    return _last_frame_at.get(node_id)
```

```python
"""Minting, hashing and revoking node bearer tokens.

Only the SHA-256 of a bearer is stored. A per-row salted hash could carry neither
a unique index nor a lookup, and the ingest path resolves a bearer to a node on
every request.
"""

import secrets
from datetime import UTC, datetime

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from core import node_state
from core.nodes import NodeToken

_TOKEN_BYTES = 32


async def mint_token(session: AsyncSession, node_id: str, *, auth_set_fingerprint: str | None) -> str:
    """Mint a bearer, store its hash, prime the cache, and return the plaintext once."""
    token = secrets.token_urlsafe(_TOKEN_BYTES)
    hashed = node_state.token_hash(token)
    session.add(NodeToken(node_id=node_id, token_hash=hashed, auth_set_fingerprint=auth_set_fingerprint))
    await session.commit()
    node_state.prime_token(hashed, node_id)
    return token


async def revoke_tokens(session: AsyncSession, node_id: str, *, reason: str, note: str | None = None) -> int:
    """Revoke every live token for a node. Returns how many were revoked."""
    rows = (
        await session.execute(
            select(NodeToken).where(NodeToken.node_id == node_id, NodeToken.revoked_at.is_(None))
        )
    ).scalars().all()
    now = datetime.now(UTC)
    for row in rows:
        row.revoked_at = now
        row.revoked_reason = reason
        row.revoked_note = note
    await session.commit()
    node_state.forget_node(node_id)
    return len(rows)


async def load_live_tokens(session: AsyncSession) -> int:
    """Prime the cache from the database. Called once at startup."""
    now = datetime.now(UTC)
    rows = (
        await session.execute(
            select(NodeToken).where(NodeToken.revoked_at.is_(None))
        )
    ).scalars().all()
    live = [r for r in rows if r.expires_at is None or r.expires_at > now]
    for row in live:
        node_state.prime_token(row.token_hash, row.node_id)
    return len(live)
```

```python
"""The in-request Mender management API lookup.

One function, so registration has one external dependency and tests have one seam.
Every failure to reach Mender raises MenderUnreachable rather than resolving to
"unknown device": the two are the same 403 on the wire, but only one of them means
every enrolment in the fleet is blocked, and that difference belongs in an alert.
"""

import base64
import hashlib
import json
import logging
import os
from dataclasses import dataclass

import httpx

logger = logging.getLogger(__name__)

MENDER_URL = os.getenv("MENDER_URL", "https://hosted.mender.io").rstrip("/")
MENDER_TOKEN = os.getenv("MENDER_MANAGEMENT_TOKEN", "")
MENDER_TIMEOUT_S = float(os.getenv("MENDER_TIMEOUT_S", "3.0"))

_transport: httpx.AsyncBaseTransport | None = None


class MenderUnreachable(Exception):
    """Mender could not be asked. Distinct from Mender answering no."""


@dataclass(frozen=True)
class MenderDeviceRecord:
    mender_device_id: str
    node_id: str
    auth_status: str
    auth_set_id: str | None
    auth_set_pubkey: str | None
    auth_set_fingerprint: str | None


def _fingerprint(pem: str) -> str:
    """SHA-256 over the DER SPKI, which is the base64 body of the PEM decoded."""
    body = "".join(line for line in pem.splitlines() if "-----" not in line)
    return hashlib.sha256(base64.b64decode(body)).hexdigest()


def _record(device: dict) -> MenderDeviceRecord:
    node_id = (device.get("identity_data") or {}).get("node_id", "")
    accepted = [s for s in device.get("auth_sets") or [] if s.get("status") == "accepted"]
    if len(accepted) > 1:
        logger.warning("mender device %s has %d accepted auth sets", device.get("id"), len(accepted))
        return MenderDeviceRecord(device.get("id", ""), node_id, "ambiguous", None, None, None)
    if not accepted:
        return MenderDeviceRecord(device.get("id", ""), node_id, device.get("status", "pending"), None, None, None)
    auth_set = accepted[0]
    pubkey = auth_set.get("pubkey")
    fingerprint = None
    if pubkey:
        try:
            fingerprint = _fingerprint(pubkey)
        except Exception:
            logger.warning("mender device %s has an undecodable pubkey", device.get("id"))
    return MenderDeviceRecord(
        device.get("id", ""), node_id, device.get("status", "accepted"),
        auth_set.get("id"), pubkey, fingerprint,
    )


async def lookup_device(node_id: str) -> MenderDeviceRecord | None:
    """Resolve node_id against Mender. None means Mender does not know it."""
    params = {"identity_data": json.dumps({"node_id": node_id}, separators=(",", ":")), "per_page": 2}
    headers = {"Authorization": f"Bearer {MENDER_TOKEN}"}
    try:
        async with httpx.AsyncClient(
            base_url=MENDER_URL, timeout=MENDER_TIMEOUT_S, transport=_transport
        ) as client:
            response = await client.get("/api/management/v2/devauth/devices", params=params, headers=headers)
    except httpx.HTTPError as exc:
        raise MenderUnreachable(str(exc)) from exc
    if response.status_code >= 500 or response.status_code == 429:
        raise MenderUnreachable(f"status {response.status_code}")
    if response.status_code != 200:
        raise MenderUnreachable(f"status {response.status_code}")
    devices = response.json()
    if not devices:
        return None
    return _record(devices[0])
```

```python
"""Per-identity registration counters, in the database rather than in memory.

The windows are an hour and a day and this service deploys on merge, so counters
that die with the process cannot reach the daily limit. A lockout every deploy
clears is not a lockout.
"""

from dataclasses import dataclass
from datetime import UTC, datetime, timedelta

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from core.nodes import NodeRegistrationLimit

HOUR_LIMIT = 5
DAY_LIMIT = 20
BASE_COOLDOWN_S = 900
MAX_COOLDOWN_S = 86400


@dataclass(frozen=True)
class LimitVerdict:
    locked: bool
    retry_after_s: int


def _cooldown_for(consecutive_lockouts: int) -> int:
    return min(BASE_COOLDOWN_S * (2 ** max(0, consecutive_lockouts - 1)), MAX_COOLDOWN_S)


async def _row(session: AsyncSession, node_id: str) -> NodeRegistrationLimit:
    row = (
        await session.execute(select(NodeRegistrationLimit).where(NodeRegistrationLimit.node_id == node_id))
    ).scalar_one_or_none()
    if row is None:
        row = NodeRegistrationLimit(node_id=node_id, hour_attempts=0, day_attempts=0, consecutive_lockouts=0)
        session.add(row)
    return row


async def check_and_count(session: AsyncSession, node_id: str, *, countable: bool) -> LimitVerdict:
    """Count this attempt if countable, then say whether the identity is locked."""
    now = datetime.now(UTC)
    row = await _row(session, node_id)
    row.last_attempt_at = now

    if row.locked_until is not None and row.locked_until > now:
        await session.commit()
        return LimitVerdict(True, int((row.locked_until - now).total_seconds()))

    if not countable:
        await session.commit()
        return LimitVerdict(False, 0)

    if row.hour_window_started_at is None or now - row.hour_window_started_at > timedelta(hours=1):
        row.hour_window_started_at = now
        row.hour_attempts = 0
    if row.day_window_started_at is None or now - row.day_window_started_at > timedelta(days=1):
        row.day_window_started_at = now
        row.day_attempts = 0

    row.hour_attempts += 1
    row.day_attempts += 1

    if row.hour_attempts > HOUR_LIMIT or row.day_attempts > DAY_LIMIT:
        row.consecutive_lockouts += 1
        cooldown = _cooldown_for(row.consecutive_lockouts)
        row.locked_until = now + timedelta(seconds=cooldown)
        await session.commit()
        return LimitVerdict(True, cooldown)

    await session.commit()
    return LimitVerdict(False, 0)


async def record_failure(session: AsyncSession, node_id: str, *, reason: str) -> None:
    row = await _row(session, node_id)
    row.last_failure_reason = reason
    row.last_failure_at = datetime.now(UTC)
    await session.commit()


async def record_success(session: AsyncSession, node_id: str) -> None:
    row = await _row(session, node_id)
    row.consecutive_lockouts = 0
    row.locked_until = None
    row.hour_attempts = 0
    row.day_attempts = 0
    await session.commit()


async def clear_lockout(session: AsyncSession, node_id: str, *, cleared_by: str, note: str | None) -> None:
    row = await _row(session, node_id)
    row.locked_until = None
    row.hour_attempts = 0
    row.day_attempts = 0
    row.cleared_at = datetime.now(UTC)
    row.cleared_by = cleared_by
    row.clear_note = note
    await session.commit()
```

`clear_lockout` deliberately leaves `consecutive_lockouts` alone: an operator clear is a shortcut through one cooldown, not an amnesty on the escalation.

```python
REFUSAL_BODY = {"error": "forbidden"}
REFUSAL_FLOOR_S = 0.35
RETRY_AFTER_BASE_S = 300
RETRY_AFTER_JITTER_S = 60


def _retry_after() -> int:
    """One jittered constant, the same for every failure class.

    A value that varied with the reason would say what the status code
    deliberately does not.
    """
    return RETRY_AFTER_BASE_S + secrets.randbelow(2 * RETRY_AFTER_JITTER_S) - RETRY_AFTER_JITTER_S


async def _refuse(started: float) -> JSONResponse:
    """Every refusal: same body, same header, same latency.

    The floor is above the Mender call's p99, so a refusal decided before the
    call and one decided after it are indistinguishable from outside.
    """
    elapsed = time.perf_counter() - started
    if elapsed < REFUSAL_FLOOR_S:
        await asyncio.sleep(REFUSAL_FLOOR_S - elapsed)
    return JSONResponse(REFUSAL_BODY, status_code=403, headers={"Retry-After": str(_retry_after())})

async def register_node(request: RegisterRequest, session: AsyncSession = Depends(get_async_session)):
    started = time.perf_counter()

    # 1. Limiters first, without exception. An unauthenticated endpoint making an
    #    outbound authenticated call per request is an amplifier in any other order.
    verdict = await check_and_count(session, request.node_id, countable=False)
    if verdict.locked:
        return await _refuse(started)

    existing = await _load_node(session, request.node_id)
    holds_valid_token = existing is not None and await _has_live_token(session, request.node_id)
    reactivated = existing is not None and _within_reactivation_window(existing)

    # 2. Mender. Unreachable alerts and refuses; it does not resolve to "unknown".
    try:
        device = await lookup_device(request.node_id)
    except MenderUnreachable:
        send_alert("mender_unreachable", f"registration for {request.node_id} could not reach Mender")
        return await _refuse(started)

    if device is None or device.auth_status != "accepted":
        return await _refuse(started)
    if holds_valid_token and not reactivated:
        send_alert("registration_held", f"token-less registration for {request.node_id} without reactivation")
        return await _refuse(started)

    # 3. Identity has resolved, so the attempt is countable and a 400 is now safe.
    counted = await check_and_count(session, request.node_id, countable=True)

    try:

    except ConfigInvalid as exc:
```

```python
async def bearer_node(request: Request) -> str:
    """Resolve the bearer to a node_id from the in-process cache. No database read."""
    header = request.headers.get("authorization", "")
    if not header.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="unauthorized")
    node_id = node_state.resolve_token(header[7:])
    if node_id is None:
        raise HTTPException(status_code=401, detail="unauthorized")
    return node_id


@router.put("/config")
async def put_config(payload: dict[str, Any], node_id: str = Depends(bearer_node),
                     session: AsyncSession = Depends(get_async_session)) -> ConfigResponse:
    try:
        config = validate_config(payload)
    except ConfigInvalid as exc:
        return JSONResponse({"error": "invalid_config", "detail": exc.field}, status_code=400)
    version = await upsert_config(session, node_id, config)
    node_state.set_active_config(node_id, version)
    return ConfigResponse(config_version=version)
```
